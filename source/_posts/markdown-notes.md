写博客之前，先把 Markdown 学会。这篇笔记整理了日常写作最常用的语法。

## 标题

```markdown
## 二级标题
### 三级标题
#### 四级标题
```

## 文字样式

- **加粗**：`**加粗**`
- *斜体*：`*斜体*`
- ~~删除线~~：`~~删除线~~`
- `行内代码`：反引号包裹
- [超链接](https://hexo.io)：`[文字](地址)`

## 列表

```markdown
- 无序列表项
- 另一项

1. 有序列表
2. 第二项
```

## 引用

> 引用一段话：简单的事情重复做，重复的事情认真做。

## 代码块

```javascript
function hello() {
  console.log("Hello, blog!");
}
```

## 图片

```markdown
![图片描述](图片地址)
```

## 表格

| 语法 | 效果 |
| ---- | ---- |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |

---

掌握了这些，日常写博客就完全够用了。更多进阶用法（脚注、公式、流程图）用到再查。
